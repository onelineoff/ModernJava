Deployment
==========

# High Level
The purpose of this is to demonstrate IaC using either Ansible or Terraform.
The following steps will be performed.
1. Create Postgres database in the cloud.
2. Deploy schema to the cloud.
3. Deploy standalone Spring Boot application to the cloud.
4. Deploye Spring Boot application in a Docker/Kubernetes environment.
5. Execute acceptance tests locally against application steps 3 and 4.
6. Repeat the above steps for multiple cloud environments
